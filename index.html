각다귀 채널 운영 도구 / Gakdagwi Channel Operations Tool

한국어

이 도구는 YouTube 채널 「각다귀」(채널 ID UC4Qd1XCACCsg2omVh-itmuQ)의 운영자 1명이 본인 채널만 관리하기 위해 자신의 Mac에서 실행하는 명령줄(CLI) 프로그램입니다. 외부 이용자 가입, 서버, 데이터베이스가 없습니다.

  • 운영자가 검수·승인한 영상의 업로드와 예약 공개 설정
  • 본인 영상의 제목·설명·태그·언어·아동용 여부·합성 콘텐츠 표시 수정, 자막·현지화·본인 채널 댓글 등록
  • 본인 재생목록 조회와 영상 추가
  • 본인 채널의 공개 통계 및 YouTube Analytics 성과 조회

English

This is a command-line program run on the operator's own Mac by the single operator of the YouTube channel "Gakdagwi" (channel ID UC4Qd1XCACCsg2omVh-itmuQ) to manage that channel only. There is no external-user sign-up, no server, and no database.

  • Uploading operator-reviewed videos and scheduling publication
  • Editing the operator's own video title, description, tags, language, made-for-kids and synthetic-media settings; adding captions, localizations and a channel-owner comment
  • Listing the operator's own playlists and adding videos to them
  • Reading public statistics and YouTube Analytics for the operator's own channel
