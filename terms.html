대상과 목적

운영자의 책임

운영자는 본인이 소유하거나 허가받은 콘텐츠만 처리하고, 게시 내용의 사실성·저작권·개인정보·아동용 설정·합성 콘텐츠 표시를 확인합니다. 업로드 및 예약 공개는 운영자가 직접 승인·실행합니다. 일반 제작 파이프라인은 게시 준비 패키지까지만 만들며 자동 게시하지 않습니다.

YouTube 서비스 조건

이 도구는 YouTube API Services를 사용합니다. 이용에는 YouTube 서비스 약관 및 관련 API 조건이 적용됩니다. 운영자는 사용 시점의 YouTube API Services Terms of Service와 Developer Policies를 확인해야 합니다. 이 초안은 정책 준수나 감사 승인 완료를 증명하지 않습니다.

인증과 데이터

운영자는 본인 Google 계정으로 권한을 부여합니다. 토큰은 로컬 저장하며 타인과 공유하지 않습니다. 데이터 처리·보관·철회 방법은 개인정보 처리방침을 따릅니다.

가용성과 변경

API 권한, 할당량, 채널 상태와 Google의 정책에 따라 요청이 거부되거나 예약이 적용되지 않을 수 있습니다. 운영자는 dry-run 계획 및 실행 후 결과를 확인하고, YouTube Studio에서 최종 상태를 확인합니다. 기능·사용 범위가 바뀌면 이 약관을 다시 검토합니다.
