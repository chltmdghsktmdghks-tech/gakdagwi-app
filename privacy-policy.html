4. 보관 기간과 삭제

  • OAuth 토큰: 인가가 유효한 동안만 보관하며, 접근을 철회하면 삭제합니다.
  • 비인가(공개) API 데이터: 캐시·트렌드 기록·공개 통계 행은 30일을 넘기지 않고 삭제합니다.
  • 인가 데이터(YouTube Analytics 포함): 30일마다 인가가 여전히 유효한지 확인하며, 확인하지 못하면 30일 초과분을 삭제합니다. 그 밖의 인가 데이터는 30일을 넘겨 보관하지 않고 삭제하거나 새로 조회해 갱신합니다.
  • 운영자는 최소 30일마다 보관 정리 도구(api_data_retention.py)를 실행합니다.
  • 삭제 요청: 아래 연락처로 요청하면 가능한 한 빨리, 늦어도 7일 이내에 관련 API 데이터를 삭제합니다.
  • 철회: 도구 내에서 철회하면 토큰을 즉시 폐기하고 7일 이내에 인가 데이터를 삭제합니다. Google 보안 설정에서 철회한 경우 30일 이내에 관련 API 데이터를 삭제합니다.

This tool uses YouTube API Services. By using this tool you agree to be bound by the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

1. Overview

A local command-line tool used by the single operator of the "Gakdagwi" channel to manage the operator's own channel. This information site collects no visitor data: no cookies, analytics scripts or forms. There is no operator-run server.

2. Data accessed and used

DataPurposeWhere stored
Google OAuth access and refresh tokens (Authorized Data)Call the APIs as the operatorOperator's Mac, secrets/youtube_token.json (mode 0600)
Own-channel video, playlist, caption and comment metadata (Authorized Data)Upload, edit, schedule, confirm playlist membershipIn memory while running; only the outcome (video ID, verification result) is saved in a result file in the video package folder
Own-channel YouTube Analytics metrics: views, average view percentage, average view duration, subscribers gained (Authorized Data)Performance reviewLocal publish_ready/analytics.md
Public API data: own-channel public statistics, public search results (non-authorized data)Performance log; topic research (themes only, no copying of others' content)Local data/youtube/, data/trends/, analytics.md

YouTube API endpoints accessed by the tool:

APIMethods
YouTube Data API v3 (OAuth)videos.insert, videos.list, videos.update, playlists.list, playlistItems.list, playlistItems.insert, captions.list, captions.insert, commentThreads.list, commentThreads.insert
YouTube Data API v3 (API key, public data)channels.list, playlistItems.list, videos.list, search.list
YouTube Analytics API v2 (OAuth)reports.query (ids=channel==MINE)

OAuth scopes: youtube.upload, youtube, yt-analytics.readonly, and youtube.force-ssl for the optional captions and comment features.

3. Sharing

Data stays on the operator's own Mac and is never sold, shared or published. Nothing leaves the Mac except the requests sent to Google/YouTube to perform the authorized operations.

4. Retention and deletion

  • OAuth tokens: kept only while authorization is active; deleted when access is revoked.
  • Non-authorized (public) API data: caches, trend records and public statistics rows are deleted within 30 calendar days.
  • Authorized Data (including YouTube Analytics): authorization is re-confirmed every 30 days; if it cannot be confirmed, data older than 30 days is deleted. Other Authorized Data is never kept beyond 30 days without being deleted or refreshed.
  • The operator runs the retention tool (api_data_retention.py) at least every 30 days.
  • Deletion requests: send a request to the contact below; related API data is deleted as soon as possible and within 7 calendar days.
  • Revocation: if access is revoked through the tool, the token is revoked right away and Authorized Data is deleted within 7 calendar days. If revoked through Google security settings, related API data is deleted within 30 calendar days.

5. How to revoke access

You can revoke this app's access at any time on the Google security settings page (https://security.google.com/settings/security/permissions).
